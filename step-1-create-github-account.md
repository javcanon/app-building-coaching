# Step 1: Create a GitHub Account

_This is the very first hands-on step. Before writing any code, you need a GitHub account.
It's free and takes about 5 minutes. (For the concepts behind all this, read
[github-basics.md](github-basics.md) alongside this step.)_

## Why this is step 1

GitHub is where your projects will live and be backed up. Everything else (installing tools,
building an app) assumes you have an account. So we start here.

## What you'll need

- An email address you check regularly.
- A few minutes.

## Click-by-click

1. Go to **https://github.com**.
2. Click **Sign up** (top right).
3. Enter your **email address**, then create a **password** and a **username**.
   - Your username is public and hard to change later, so pick something clean and
     professional (your name or a variation is a safe choice).
4. Verify you're human (a puzzle), then click **Create account**.
5. **Check your email** for a verification code from GitHub and enter it. This confirms the
   account is really yours.
6. When asked about a plan, choose **Free**. It's all you need to start.

## Turn on two-factor authentication (2FA), do this now

GitHub requires it, and it protects your account. Right after signing up:

1. Click your **profile picture** (top right) then **Settings**.
2. In the left menu, click **Password and authentication**.
3. Under **Two-factor authentication**, click **Enable** and follow the prompts.
   - The easiest method is an **authenticator app** on your phone (e.g. Google Authenticator,
     Microsoft Authenticator, or Authy).
4. **Save your recovery codes** somewhere safe (a password manager, or print them). These get
   you back in if you lose your phone. Do not skip this, losing access is a real headache.

## You're done when

- You can log in at github.com and see your (empty) profile.
- 2FA is enabled and your recovery codes are saved.

## Try it: explore a real repo

To see what you'll be working with, open this very repository in your browser:
**https://github.com/javcanon/app-building-coaching**

- Click on a file (like `github-basics.md`) to read it.
- Click **History** (or the commit list) to see how every change is tracked over time. That
  timeline is Git doing its job, exactly what the basics doc describes.
